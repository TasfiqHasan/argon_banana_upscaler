# Argon -> Yellow Banana 4K Automation Pipeline

An automated, cost-free image synthesis and upscaling workflow:
1. **Argon Base Generation**: Generates 2K base images using Google AI Studio (`imagen-3.0-generate-002` / Gemini multimodal models).
2. **Yellow Banana AI Upscaling**: Upscales 2K assets to true 4K Ultra HD (3840×2160 or 4096×4096) with micro-contrast and edge sharpening.
3. **Auto-Download & Logging**: Automatically saves the final 4K PNG file and records a structured JSON audit log.

---

## 1. Free Setup (Zero Cost)

Google AI Studio provides a generous free tier for developers:

1. Go to [Google AI Studio API Keys](https://aistudio.google.com/app/apikey).
2. Click **Create API Key**.
3. Copy your key and place it into `.env`:
   ```bash
   cp .env.example .env
   ```
   Edit `.env`:
   ```env
   GEMINI_API_KEY=your_free_ai_studio_api_key_here
   ```

---

## 2. Quickstart

### Run the Interactive Menu
```bash
python main.py
```

### Generate & Upscale in One Command
```bash
python main.py --prompt "Cinematic cyberpunk street market in Tokyo at midnight, neon reflection, 8k" --aspect 16:9
```

### Upscale an Existing Local Image Directly
```bash
python main.py --upscale-only "path/to/your/image.png" --aspect 16:9
```

### Test in Dry-Run Mode (No API Key Required)
```bash
python main.py --prompt "Futuristic quantum laboratory" --dry-run
```

## 3. Supported Aspect Ratios & Resolutions

| Preset | Aspect Ratio | Target 4K Dimensions | Ideal For |
|---|---|---|---|
| `16:9` | 16:9 | 3840 × 2160 | Desktop Wallpapers, Video Frames |
| `1:1` | 1:1 | 4096 × 4096 | Square Avatars, Product Artwork |
| `4:3` | 4:3 | 3840 × 2880 | Photography, Vintage / Classic Format |
| `9:16` | 9:16 | 2160 × 3840 | Smartphone Wallpapers, Stories / Reels |

---

## 4. Output Structure

All outputs are saved to the `outputs/` folder:
- `base_2k_<timestamp>.png`: Base 2K image generated by Argon.
- `downloaded_4k_<timestamp>.png`: Mastered 4K Ultra HD image.
- `meta_<timestamp>.json`: Audit trail containing prompt, resolution, generation time, and file paths.
